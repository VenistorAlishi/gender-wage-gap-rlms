## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### Проблема 1: Ошибка при загрузке данных

**Симптом:** `FileNotFoundError` или ошибка чтения .dta файла

**Решение:**
- Убедитесь, что файл `data/RLMS_IND_1994_2024_v3_rus.dta` существует
- Проверьте путь к файлу в коде (должен быть `data/RLMS_IND_1994_2024_v3_rus.dta`)

### Проблема 2: Переменные не найдены

**Симптом:** Предупреждения о том, что переменные не найдены

**Решение:**
- Это нормально, если некоторые переменные отсутствуют в данных
- Код автоматически адаптируется и использует доступные переменные
- Проверьте кодбук RLMS для правильных названий переменных

### Проблема 3: Ошибка при оценке моделей

**Симптом:** Ошибка при вызове `sm.OLS().fit()`

**Решение:**
- Убедитесь, что установлен `statsmodels`: `pip install statsmodels`
- Проверьте, что в данных достаточно наблюдений (минимум 10-20)
- Проверьте, что нет пропущенных значений в ключевых переменных

### Проблема 4: Проблемы с кодировкой (кириллица)

**Симптом:** Вместо русского текста видны кракозябры

**Решение:**
- В Windows это нормально для консоли
- В Jupyter Notebook текст должен отображаться корректно
- Если проблема в графиках, проверьте настройки matplotlib
