Откройте терминал в папке проекта и выполните:



## ШАГ 2: Скачивание данных RLMS

1. Перейдите на сайт RLMS: https://www.hse.ru/rlms/spss
2. Скачайте данные для **2010** и **2020** годов
3. Отфильтруйте данные по регионам **Москва** и **Брянск**
4. Сохраните файлы в папку `data/` с понятными названиями, например:
   - `rlms_2010_moscow.sav` (или `.csv`)
   - `rlms_2010_bryansk.sav` (или `.csv`)
   - `rlms_2020_moscow.sav` (или `.csv`)
   - `rlms_2020_bryansk.sav` (или `.csv`)

## ВАЖНЫЕ ЗАМЕЧАНИЯ

### Названия переменных в RLMS
- Названия переменных могут отличаться в разных волнах RLMS
- **ОБЯЗАТЕЛЬНО** проверьте кодбук перед использованием
- Примерные названия указаны в ноутбуке, но они могут не совпадать с вашими данными

### Формат данных
- RLMS предоставляет данные в формате SPSS (.sav)
- Для работы с .sav файлами используйте библиотеку `pyreadstat`
- Если данные в CSV/Excel, используйте `pd.read_csv()` или `pd.read_excel()`

### Качество данных
- Проверьте пропущенные значения
- Исключите выбросы (экстремальные значения заработных плат)
- Ограничьте выборку работающими индивидами определённого возраста (например, 18-65 лет)

### Интерпретация результатов
- Коэффициент `female` интерпретируется как процентное изменение заработной платы
- Если `beta_female = -0.15`, то заработные платы женщин на 15% ниже
- Будьте осторожны в выводах о дискриминации — "необъяснённый" разрыв может быть связан с ненаблюдаемыми характеристиками
