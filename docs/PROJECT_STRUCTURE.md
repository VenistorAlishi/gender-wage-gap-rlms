## Описание файлов

### Основные файлы

#### `gender_wage_gap_analysis.ipynb`
Основной Jupyter Notebook с полным анализом:
- Загрузка и подготовка данных
- Описательная статистика
- Оценка эконометрических моделей
- Проверка предпосылок Гаусса-Маркова
- Интерпретация результатов

#### `README.md`
Главный файл описания проекта для GitHub. Содержит:
- Описание проекта
- Инструкции по установке
- Структуру проекта
- Ссылки на документацию

#### `requirements.txt`
Список зависимостей Python для проекта.

---

### Папка `docs/`

#### `ТЕОРЕТИЧЕСКАЯ_ЧАСТЬ.md`
Ответы на вопросы по учебнику Стока и Уотсона:
- Определение гендерного разрыва
- Методы измерения
- Факторы влияния
- Эконометрические модели

#### `СТРУКТУРА_ДОКЛАДА.md`
Подробная структура доклада/отчёта с разделами и подразделами.

#### `ОПИСАНИЕ_ПЕРЕМЕННЫХ_И_МОДЕЛЕЙ.md`
Описание всех переменных и спецификация моделей.

#### `ИНСТРУКЦИЯ.md`
Пошаговая инструкция по использованию проекта.

#### `ПЛАН_ДЕЙСТВИЙ.md`
Подробный план работы с чеклистами по этапам.

#### `КРАТКИЙ_ПЛАН.md`
Краткая версия плана для быстрого просмотра.

#### `СТАТУС_ПРОЕКТА.md`
Текущий статус проекта и что нужно сделать.

#### `НОВЫЕ_МАТЕРИАЛЫ.md`
Описание новых добавленных материалов.

---

### Папка `materials/`

Содержит учебные материалы и методички:
- Задание на проект
- Методичка по практическим заданиям
- Ликбез по контрольным и инструментальным переменным
- Кодбук RLMS
- Stata скрипт с примерами

---

### Папки с данными

#### `data/`
Содержит данные RLMS (не включены в Git из-за размера).

#### `results/`
Результаты анализа (таблицы, сводки моделей).

#### `figures/`
Графики и визуализации.

---

## Рекомендации по организации

1. **Документация** — все файлы документации в папке `docs/`
2. **Материалы** — учебные материалы в папке `materials/`
3. **Данные** — данные в `data/` (не в Git)
4. **Результаты** — результаты в `results/`
5. **Графики** — графики в `figures/`

---

## Для GitHub

Рекомендуется:
- ✅ Включить в репозиторий: код, документацию, README
- ❌ Не включать: данные (слишком большие), результаты (генерируются), PDF (кроме важных)
