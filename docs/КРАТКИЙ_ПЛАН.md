# КРАТКИЙ ПЛАН ДЕЙСТВИЙ
## Быстрая шпаргалка для выполнения проекта

---

## 📚 ЭТАП 1: ПОДГОТОВКА (1-2 дня)
1. Изучить задание и теоретическую часть
2. Просмотреть структуру проекта
3. Установить Python и библиотеки

## 📥 ЭТАП 2: ДАННЫЕ (2-3 дня)
1. Скачать данные RLMS (2010, 2020, Москва, Брянск)
2. Изучить кодбук RLMS
3. Найти названия переменных

## 💻 ЭТАП 3: АНАЛИЗ (3-4 дня)
1. Открыть ноутбук `gender_wage_gap_analysis.ipynb`
2. Загрузить данные (раскомментировать код)
3. Подготовить данные (создать переменные)
4. Описательная статистика
5. Оценить 4-6 моделей
6. Проверить предпосылки
7. Выбрать лучшую модель
8. Интерпретировать результаты

## 📝 ЭТАП 4: ДОКЛАД (2-3 дня)
1. Использовать структуру из `СТРУКТУРА_ДОКЛАДА.md`
2. Написать все разделы
3. Вставить таблицы и графики
4. Оформить документ

## 🎤 ЭТАП 5: ПРЕЗЕНТАЦИЯ (1-2 дня)
1. Создать 10-15 слайдов
2. Подготовить устное выступление
3. Прорепетировать

## ✅ ЭТАП 6: ПРОВЕРКА (1 день)
1. Проверить все файлы
2. Соответствие требованиям
3. Резервная копия
