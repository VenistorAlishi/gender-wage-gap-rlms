### 3. к проекту.do
**Stata скрипт с примерами кода для анализа**

Содержит примеры:
- Визуального анализа (графики)
- Описательных статистик
- Корреляционной матрицы
- Оценивания регрессий
- Проверки предпосылок теоремы Гаусса-Маркова:
  - Тест Рамсея (RESET) на правильность спецификации
  - Тест Бокса-Кокса для выбора функциональной формы
  - Тест Чоу на структурный сдвиг
  - VIF для проверки мультиколлинеарности
  - Тесты на гетероскедастичность
  - Тесты на нормальность остатков

**Как использовать:**
- Используйте как справочник по тестам
- Адаптируйте код под Python (в ноутбуке уже есть аналогичные тесты)
- Сверьтесь с требованиями к проверке предпосылок
