## 4. ЭКОНОМЕТРИЧЕСКИЕ МОДЕЛИ

### 4.1. Базовая модель

**Модель 1: Простая модель с контролем основных характеристик**

$$
\ln(W_i) = \beta_0 + \beta_1 Female_i + \beta_2 Age_i + \beta_3 Age_i^2 + \beta_4 Education_i + \beta_5 Experience_i + \beta_6 Experience_i^2 + u_i
$$

**Гипотезы:**
- $H_0: \beta_1 = 0$ — гендерного разрыва нет
- $H_1: \beta_1 < 0$ — заработные платы женщин ниже заработных плат мужчин

### 4.2. Альтернативные модели

**Модель 2: С контролем семейного положения**

$$
\ln(W_i) = \beta_0 + \beta_1 Female_i + \beta_2 Age_i + \beta_3 Age_i^2 + \beta_4 Education_i + \beta_5 Experience_i + \beta_6 Experience_i^2 + \beta_7 Married_i + u_i
$$

**Модель 3: С контролем профессии и отрасли**

$$
\ln(W_i) = \beta_0 + \beta_1 Female_i + \beta_2 Age_i + \beta_3 Age_i^2 + \beta_4 Education_i + \beta_5 Experience_i + \beta_6 Experience_i^2 + \beta_7 Married_i + \gamma' Profession_i + \delta' Industry_i + u_i
$$

**Модель 4: С контролем региона и года**

$$
\ln(W_i) = \beta_0 + \beta_1 Female_i + \beta_2 Age_i + \beta_3 Age_i^2 + \beta_4 Education_i + \beta_5 Experience_i + \beta_6 Experience_i^2 + \beta_7 Married_i + \beta_8 Region_i + \beta_9 Year_i + \gamma' Profession_i + \delta' Industry_i + u_i
$$

**Модель 5: С взаимодействием пола и региона**

$$
\ln(W_i) = \beta_0 + \beta_1 Female_i + \beta_2 Region_i + \beta_3 (Female_i \times Region_i) + \ldots + u_i
$$

**Модель 6: С взаимодействием пола и года**

$$
\ln(W_i) = \beta_0 + \beta_1 Female_i + \beta_2 Year_i + \beta_3 (Female_i \times Year_i) + \ldots + u_i
$$

### 4.3. Обоснование выбора моделей
- Постепенное добавление контрольных переменных
- Проверка устойчивости оценки коэффициента $\beta_1$
- Учёт возможных источников смещения
