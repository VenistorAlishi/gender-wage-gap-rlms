## 🚀 СОЗДАНИЕ РЕПОЗИТОРИЯ НА GITHUB

### Шаг 1: Инициализация Git
```bash
git init
git add .
git commit -m "Initial commit: Проект по эконометрике - исследование гендерного разрыва"
```

### Шаг 2: Создание репозитория на GitHub
1. Перейдите на https://github.com/new
2. Название: `gender-wage-gap-rlms` (или другое)
3. Описание: "Исследование гендерного разрыва в заработных платах на данных RLMS"
4. НЕ добавляйте README, .gitignore, LICENSE (они уже есть)
5. Создайте репозиторий

### Шаг 3: Подключение и загрузка
```bash
git remote add origin https://github.com/YOUR_USERNAME/gender-wage-gap-rlms.git
git branch -M main
git push -u origin main
```
