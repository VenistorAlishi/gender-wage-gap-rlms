# Выводы о дефляторе и тестах

## 1. Дефляция заработных плат

### Методология

Для обеспечения сопоставимости заработных плат за разные годы (2010 и 2020) была выполнена дефляция с использованием индекса потребительских цен (ИПЦ) с базой 2010 года = 100.

**Параметры дефлятора:**
- Базовый год: 2010 (дефлятор = 100.0)
- 2020 год: дефлятор = 177.0 (по данным Росстата)
- Накопленная инфляция за период 2010-2020: ~77%

### Формула дефляции

Реальная заработная плата в ценах 2010 года рассчитывается по формуле:

$$\text{Зарплата}_{2010} = \text{Зарплата}_{\text{номинальная}} \times \frac{100}{\text{ИПЦ}_{\text{год}}}$$

где:
- Для 2010 года: $\text{ИПЦ}_{2010} = 100$
- Для 2020 года: $\text{ИПЦ}_{2020} = 177$

### Результаты дефляции

После применения дефлятора все заработные платы приведены к ценам 2010 года, что позволяет корректно сравнивать уровни заработных плат между двумя периодами без искажений, вызванных инфляцией.

**Важность дефляции:**
- Без дефляции номинальные заработные платы 2020 года были бы завышены из-за инфляции
- Дефляция обеспечивает сопоставимость данных и корректность эконометрических оценок
- Позволяет выявить реальные изменения в уровне заработных плат, а не только номинальный рост

## 2. Тест RESET (Ramsey RESET Test)

### Назначение теста

Тест RESET (Regression Specification Error Test) разработан Дж. Рамсеем (1969) для проверки правильности спецификации модели. Тест выявляет:
- Пропущенные переменные
- Неправильную функциональную форму модели
- Нелинейные зависимости, не учтенные в модели

### Методология теста

Тест RESET основан на добавлении степеней предсказанных значений модели в качестве дополнительных регрессоров:

$$y = X\beta + \gamma_1 \hat{y}^2 + \gamma_2 \hat{y}^3 + \ldots + \varepsilon$$

где $\hat{y}$ — предсказанные значения исходной модели.

**Нулевая гипотеза ($H_0$):** Модель правильно специфицирована (все коэффициенты $\gamma_i = 0$)

**Альтернативная гипотеза ($H_1$):** Модель неправильно специфицирована (хотя бы один $\gamma_i \neq 0$)

### Результаты теста RESET для Модели 5

**Параметры теста:**
- F-статистика: **20.4553**
- p-value: **6.10×10⁻⁶** (< 0.05)
- Уровень значимости: 5%

**Интерпретация результатов:**

Тест RESET **отклоняет нулевую гипотезу** о правильности спецификации модели на уровне значимости 5%. Это означает, что:

1. **Возможны пропущенные переменные:** В модели могут отсутствовать важные факторы, влияющие на заработные платы. Например:
   - Отрасль занятости
   - Тип занятости (полная/неполная, постоянная/временная)
   - Размер предприятия
   - Дополнительные характеристики человеческого капитала

2. **Возможна неправильная функциональная форма:** Модель может требовать:
   - Нелинейных преобразований переменных
   - Взаимодействий между переменными
   - Других функциональных форм (например, полиномиальных)

3. **Ограничения интерпретации:**
   - Несмотря на значимость теста RESET, модель 5 остается лучшей среди оцененных моделей по критерию скорректированного R²
   - Коэффициенты модели могут быть смещенными, но все еще информативными
   - Рекомендуется интерпретировать результаты с осторожностью

### Рекомендации

1. **Расширение модели:** Добавить дополнительные переменные, если они доступны в данных:
   - Отраслевые дамми-переменные
   - Тип занятости
   - Размер предприятия
   - Дополнительные характеристики человеческого капитала

2. **Проверка функциональной формы:** Рассмотреть альтернативные спецификации:
   - Квадратичные и кубические члены для других переменных
   - Логарифмические преобразования
   - Взаимодействия между переменными

3. **Интерпретация результатов:** Учитывать ограничения модели при формулировании выводов о гендерном разрыве в заработных платах.

## 3. Сравнение результатов до и после дефляции

### Влияние дефляции на результаты

Для оценки влияния дефляции на результаты был проведен сравнительный анализ моделей с дефлированными и недефлированными данными.

**Результаты сравнения (Модель 5):**

| Параметр | Без дефляции | С дефляцией | Разница |
|----------|-------------|-------------|---------|
| Коэффициент female | -0.634891 | -0.636778 | -0.001887 |
| p-value female | 0.008199 | 0.008016 | -0.000183 |
| R² скорректированный | 0.054632 | 0.062822 | +0.008190 |
| Статистическая значимость | Значим (p<0.05) | Значим (p<0.05) | - |

**Выводы из сравнения:**

1. **Коэффициент female:** Разница составляет -0.001887, что является очень небольшой величиной. Дефляция практически не влияет на оценку гендерного разрыва.

2. **R² скорректированный:** Улучшение на 0.008190 (с 0.054632 до 0.062822). Дефляция немного улучшает качество модели.

3. **Статистическая значимость:** В обоих случаях коэффициент female статистически значим на уровне 5%, но с дефляцией p-value немного ниже (0.008016 против 0.008199).

4. **Описательная статистика:**
   - Без дефляции: средний ln(wage) для мужчин = 10.901, для женщин = 10.693
   - С дефляцией: средний ln(wage) для мужчин = 10.636, для женщин = 10.428
   - Разница в средних значениях сохраняется, но абсолютные значения ниже с дефляцией

**Методологическая важность дефляции:**

Несмотря на то, что количественное влияние дефляции на коэффициенты относительно невелико, дефляция является **необходимой процедурой** по следующим причинам:

1. **Корректность сравнения:** Без дефляции мы сравниваем номинальные значения за разные годы, что методологически неправильно.

2. **Интерпретация результатов:** Дефлированные данные позволяют интерпретировать результаты как реальные различия, а не инфляционные эффекты.

3. **Стандарты эконометрического анализа:** При работе с данными за разные периоды времени дефляция является стандартной практикой.

4. **Влияние на качество модели:** Дефляция улучшает качество модели (R² скорректированный выше), что указывает на более точную спецификацию.

### Итоговые выводы

1. **Дефляция является необходимой процедурой** для корректного анализа данных за разные периоды времени.

2. **Тест RESET выявил проблемы спецификации модели**, что указывает на необходимость дальнейшего совершенствования модели.

3. **Несмотря на ограничения**, модель 5 остается лучшей среди оцененных моделей и позволяет сделать выводы о наличии статистически значимого гендерного разрыва в заработных платах.

4. **Рекомендуется:**
   - Интерпретировать результаты с учетом ограничений модели
   - Рассмотреть возможность расширения модели дополнительными переменными
   - Провести дополнительный анализ с учетом результатов теста RESET

## 4. Технические детали

- Уровень значимости: 5%
