## 📋 Описание проекта

Проект посвящён исследованию гендерного разрыва в заработных платах в России на основе данных Российского мониторинга экономического положения и здоровья населения НИУ ВШЭ (RLMS) за 2010 и 2020 годы для регионов **Москва** и **Тула**.

Проект включает полный эконометрический анализ с проверкой предпосылок теоремы Гаусса-Маркова и интерпретацией результатов.

### Цель исследования
Оценить наличие и динамику гендерного разрыва в заработных платах с учётом различных факторов (образование, опыт, профессия, отрасль, регион, время).

### Задачи исследования
1. Проанализировать теоретические подходы к измерению гендерного разрыва
2. Оценить гендерный разрыв в заработных платах с учётом различных факторов
3. Проверить гипотезы о наличии и динамике гендерного разрыва
4. Сравнить результаты для разных регионов и временных периодов

## 📊 Методология

### Эконометрические модели

1. **Модель 1:** Базовая модель с контролем основных характеристик
2. **Модель 2:** С контролем семейного положения
3. **Модель 4:** С контролем региона и года
4. **Модель 6:** С взаимодействием пола и года

### Методы анализа

- Множественная линейная регрессия (OLS)
- Проверка предпосылок теоремы Гаусса-Маркова:
  - Тест Рамсея (RESET) на правильность спецификации
  - Тесты на гетероскедастичность (Бройша-Пагана, Уайта)
  - Проверка мультиколлинеарности (VIF)
  - Тесты на нормальность остатков
- Робастные стандартные ошибки (при наличии гетероскедастичности)
- Сравнительный анализ моделей

### Источник данных
Российский мониторинг экономического положения и здоровья населения НИУ ВШЭ (RLMS-HSE)

- Пол (дамми-переменная)
- Возраст и квадрат возраста
- Образование
- Опыт работы и квадрат опыта
- Семейное положение
- Регион (Москва/Тула)
- Год (2010/2020)
