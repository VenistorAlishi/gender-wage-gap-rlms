### ШАГ 5: Подготовить презентацию

Используйте структуру из `docs/СТРУКТУРА_ДОКЛАДА.md` (раздел "РЕКОМЕНДАЦИИ ПО ОФОРМЛЕНИЮ ПРЕЗЕНТАЦИИ"):

**Структура презентации (10-15 слайдов):**

   - Название работы
   - Автор, учебное заведение, курс
   - Дата

2. **Актуальность и цель исследования** (1-2 слайда)
   - Из раздела 1 доклада

3. **Теоретические основы** (1-2 слайда)
   - Определение гендерного разрыва
   - Методы измерения
   - Из раздела 2 доклада

4. **Данные и методология** (1-2 слайда)
   - Описание RLMS
   - Описание переменных
   - Описательная статистика
   - Из раздела 3 доклада

5. **Эконометрические модели** (1-2 слайда)
   - Базовая модель
   - Альтернативные модели
   - Из раздела 4 доклада

6. **Результаты** (3-4 слайда)
   - Основные результаты оценивания (таблица сравнения моделей)
   - Проверка предпосылок (кратко)
   - Интерпретация (величина разрыва, динамика, региональные различия)
   - Из разделов 5 и 6 доклада

7. **Выводы** (1 слайд)
   - Краткое резюме основных результатов
   - Из раздела 6 доклада

8. **Спасибо за внимание!**

**Рекомендации:**
- Используйте графики из папки `figures/`
- Вставьте таблицу сравнения моделей из `results/comparison_table.csv`
- Выделите ключевые цифры (величина разрыва, статистическая значимость)
- Подготовьте устное выступление на 5-7 минут

## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: Анализ не завершается

**Причина:** Данные очень большие (14.9 GB), анализ может занять много времени

**Решение:**
- Подождите еще 10-20 минут
- Проверьте использование памяти в диспетчере задач
- Если процесс завис, перезапустите: `python execute_full_analysis.py`

### Проблема 2: Ошибка при загрузке данных

**Причина:** Файл данных не найден или поврежден

**Решение:**
- Убедитесь, что файл `data/RLMS_IND_1994_2024_v3_rus.dta` существует
- Проверьте размер файла (должен быть ~14.9 GB)

### Проблема 3: Доклад не заполняется

**Причина:** Файл `results/analysis_summary.json` не создан

**Решение:**
- Убедитесь, что анализ завершился успешно
- Проверьте наличие файла `results/analysis_summary.json`
- Если файла нет, запустите анализ заново

### Проблема 4: Недостаточно памяти

**Причина:** Данные очень большие, не хватает оперативной памяти

**Решение:**
- Закройте другие программы
- Используйте компьютер с большим объемом RAM
- Можно попробовать обработать данные по частям (требует модификации кода)
