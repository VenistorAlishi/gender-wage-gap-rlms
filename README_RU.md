## 📋 О ПРОЕКТЕ

Проект посвящён исследованию гендерного разрыва в заработных платах в России на основе данных RLMS за 2010 и 2020 годы для регионов **Москва** и **Тула**.

Включает полный эконометрический анализ с проверкой предпосылок теоремы Гаусса-Маркова.

---

## 🚀 БЫСТРЫЙ СТАРТ

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Запустите ноутбук:**
   ```bash
   jupyter notebook gender_wage_gap_analysis.ipynb
   ```

3. **Запустите все ячейки:** Cell → Run All
