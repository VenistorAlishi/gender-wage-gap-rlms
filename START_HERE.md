## ⚡ Что делать прямо сейчас

### 1. Организуйте файлы (5 минут)
```powershell
.\organize_files.ps1
```
Или переместите файлы вручную (см. `ORGANIZATION_GUIDE.md`)

### 2. Запустите анализ (5 минут)
```bash
jupyter notebook gender_wage_gap_analysis.ipynb
```
Запустите все ячейки (Cell → Run All)

### 3. Создайте репозиторий на GitHub (10 минут)
Следуйте инструкциям в `GITHUB_SETUP.md`
