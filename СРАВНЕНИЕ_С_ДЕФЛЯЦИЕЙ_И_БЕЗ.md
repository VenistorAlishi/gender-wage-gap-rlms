# Сравнение результатов с дефляцией и без дефляции

## Введение

Для оценки влияния дефляции на результаты эконометрического анализа был проведен сравнительный анализ моделей с дефлированными и недефлированными данными. Дефляция была выполнена с использованием индекса потребительских цен (ИПЦ) с базой 2010 года = 100.

**Параметры дефлятора:**
- Базовый год: 2010 (дефлятор = 100.0)
- 2020 год: дефлятор = 177.0 (по данным Росстата)
- Накопленная инфляция за период 2010-2020: ~77%

## 4. Выводы из сравнения

### 4.1. Количественное влияние дефляции

1. **Коэффициент female в лучшей модели (Модель 5):**
   - Разница составляет -0.0019, что является очень небольшой величиной
   - Дефляция практически не влияет на оценку гендерного разрыва

2. **R² скорректированный:**
   - Улучшение на 0.0082 (с 0.0546 до 0.0628)
   - Дефляция немного улучшает качество модели

3. **Статистическая значимость:**
   - В обоих случаях коэффициент female статистически значим на уровне 5%
   - С дефляцией p-value немного ниже (0.0080 против 0.0082)

4. **Описательная статистика:**
   - Без дефляции: средний ln(wage) для мужчин = 10.901, для женщин = 10.693
   - С дефляцией: средний ln(wage) для мужчин = 10.636, для женщин = 10.428
   - Разница в средних значениях сохраняется, но абсолютные значения ниже с дефляцией

### 4.2. Методологическая важность дефляции

Несмотря на то, что количественное влияние дефляции на коэффициенты относительно невелико, дефляция является **необходимой процедурой** по следующим причинам:

1. **Корректность сравнения:**
   - Без дефляции мы сравниваем номинальные значения за разные годы, что методологически неправильно
   - Дефляция обеспечивает сопоставимость данных за разные периоды времени

2. **Интерпретация результатов:**
   - Дефлированные данные позволяют интерпретировать результаты как реальные различия, а не инфляционные эффекты
   - Позволяет выявить реальные изменения в уровне заработных плат, а не только номинальный рост

3. **Стандарты эконометрического анализа:**
   - При работе с данными за разные периоды времени дефляция является стандартной практикой
   - Соответствует требованиям научной методологии

4. **Влияние на качество модели:**
   - Дефляция улучшает качество модели (R² скорректированный выше), что указывает на более точную спецификацию
   - Это подтверждает правильность применения дефляции

### 4.3. Практические рекомендации

1. **Использование дефлированных данных:**
   - Рекомендуется использовать дефлированные данные для всех эконометрических оценок
   - Это обеспечивает корректность сравнения между периодами времени

2. **Интерпретация результатов:**
   - При интерпретации результатов необходимо указывать, что данные дефлированы к ценам базового года
   - Это важно для понимания реальных, а не номинальных различий

3. **Публикация результатов:**
   - В научных публикациях необходимо указывать метод дефляции и параметры дефлятора
   - Это повышает прозрачность и воспроизводимость исследования

## 5. Технические детали

### 5.1. Формула дефляции

Реальная заработная плата в ценах 2010 года рассчитывается по формуле:

$$\text{Зарплата}_{2010} = \text{Зарплата}_{\text{номинальная}} \times \frac{100}{\text{ИПЦ}_{\text{год}}}$$

где:
- Для 2010 года: $\text{ИПЦ}_{2010} = 100$
- Для 2020 года: $\text{ИПЦ}_{2020} = 177$

### 5.2. Источник данных дефлятора

- **Источник:** Росстат (Индекс потребительских цен)
- **Базовый год:** 2010
- **Дефлятор 2020 года:** 177.0 (к базе 2010 года)
- **Метод расчета:** Прямое деление номинальных значений на дефлятор

### 5.3. Примечания

- Все результаты с дефляцией основаны на данных, приведенных к ценам 2010 года
- Результаты без дефляции основаны на номинальных значениях заработных плат
- Размер выборки одинаков в обоих случаях: 526 наблюдений
